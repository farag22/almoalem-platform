# منصة تعليم

منصة تعليمية متكاملة للمعلمين وأولياء الأمور مبنية بـ **React + Vite + Tailwind CSS + Supabase**، واجهة عربية كاملة RTL متجاوبة مع الهاتف والكمبيوتر.

## المميزات

- **تسجيل دخول المعلمين** بالبريد الإلكتروني وكلمة المرور (Supabase Auth).
- **دخول أولياء الأمور** عبر كود الطالب فقط، بصلاحية قراءة فقط.
- **لوحة تحكم المعلم**:
  - إدارة المجاميع مع لون مخصص لكل مجموعة.
  - إدارة الطلاب: كود ولي الأمر، رقم الموبايل، المجموعة.
  - الحضور والغياب اليومي بنقرة واحدة (حاضر / غائب / متأخر) مع تصدير CSV.
  - المصاريف والمدفوعات الشهرية لكل طالب.

## المتطلبات

- Node.js 18+
- مشروع Supabase جاهز

## الإعداد والتشغيل

### 1) تثبيت الاعتماديات

```bash
npm install
```

### 2) إعداد Supabase

**أ. تنفيذ مخطط قاعدة البيانات:**

من لوحة Supabase افتح **SQL Editor** والصق محتوى ملف `supabase/schema.sql` ثم نفّذه. سيُنشئ ذلك الجداول وسياسات الأمان ودوال أولياء الأمور تلقائياً.

**ب. ضبط مفتاح الاتصال:**

العميل موحّد ومضبوط مسبقاً في `src/lib/supabase.js` بقيم الاتصال المباشرة (لا يعتمد على ملفات `.env`):

```js
export const supabase = createClient(
  'https://kqorwabdnnhovsyqxogq.supabase.co',
  'ضع_المفتاح_العام_هنا'
);
```

المفتاح المطلوب هو **Anon / Publishable key** من `Settings → API → Project API keys`.

> لا تضع أبداً Secret key في الكود أو الملفات.

### 3) تشغيل التطوير

```bash
npm run dev
```

### 4) بيانات تجريبية (اختياري)

بعد تسجيل دخول المعلم لأول مرة، يمكنك تحميل بيانات تجريبية (مجاميع + طلاب + حضور + مدفوعات) بتنفيذ الدالة من SQL Editor:

```sql
select public.seed_demo_data();
```

> يجب أن يكون المعلم مسجلاً الدخول في نفس الجلسة عند تنفيذها.

## هيكل المشروع

```
src/
├── components/
│   ├── layout/DashboardLayout.jsx   # التخطيط العام للوحة
│   └── ui/                          # مكونات مشتركة (Modal, Toast)
├── context/AuthContext.jsx          # إدارة الجلسة
├── lib/
│   ├── supabase.js                  # عميل Supabase
│   └── constants.js                 # ألوان وشهور وأوضاع الحضور
└── pages/
    ├── TeacherLogin.jsx             # دخول المعلم
    ├── ParentLogin.jsx              # دخول ولي الأمر بالكود
    ├── ParentView.jsx               # عرض ولي الأمر (قراءة فقط)
    ├── Dashboard.jsx                # نظرة عامة
    ├── GroupsPage.jsx               # إدارة المجاميع
    ├── StudentsPage.jsx             # إدارة الطلاب
    ├── AttendancePage.jsx           # الحضور والغياب
    └── PaymentsPage.jsx             # المصاريف والمدفوعات
```

## الأمان

- تفعيل **Row Level Security** على جميع الجداول؛ المعلم يصل فقط لبياناته.
- ولي الأمر لا يملك حساباً، ويدخل عبر دالة `get_student_by_parent_code` بصلاحية قراءة فقط.
- مفاتيح الاتصال تُقرأ من متغيرات البيئة ولا تُضمّن في الكود.
